# MAWD 2026 해커톤 준비

MAWD Start-up Challenge(2026년 11월 14일부터 15일) 10팀 마이크의 작업 공간이다. 지금 들어 있는 것은 AI 콘텐츠 보좌관의 기획서와 화면 목업, 콘텐츠 점수 스크립트, 후원사 API 호출 안내다.

## AI 콘텐츠 보좌관

의원실이 이미 낸 발언, 법안, 일정을 유권자가 읽기 쉬운 콘텐츠로 바꾸고, 다음에 무엇을 낼지 정하는 일을 돕는 콘텐츠 에이전트다. 여당, 야당, 무소속 어느 의원실에도 같은 질문과 같은 기준을 쓴다.

| 폴더 | 내용 |
|---|---|
| `docs/기획서.md` | 문제, 고객, 흐름, 콘텐츠 점수, 규정, 오픈소스 |
| `prototype/index.html` | 화면 목업 10장. 브라우저로 열면 된다. `?only=3`처럼 붙이면 한 장만 보인다 |
| `prototype/mockups/` | 목업을 이미지로 내보낸 PNG 10장 |
| `scoring/` | Articul8 Bivia로 글에 점수를 매기는 스크립트와 결과 |
| `api/` | 후원사 API(Liner, VAPI, 스티비, Articul8, Readray) 호출 안내와 키 확인 스크립트 |

## 자료의 출처

목업과 점수에 쓴 글과 수치는 모두 공개 자료다. 서울특별시의회 회의록과 보도자료 게시판, 서울시 보도자료와 열린데이터광장 통계, 국회 공식 페이지, 정당 공식 홈페이지와 유튜브에서 원문 그대로 옮겼다. 초안 작업대의 글은 도구가 원자료에서 만든 초안이고 의원실이 낸 글이 아니다. 배경 그림은 생성 이미지다.

콘텐츠 점수는 모델 판정이며 사람이 검증한 값이 아니다. 표본이 작아 정당 전체의 경향으로 읽을 수 없다.

## 키

API 키는 저장소에 넣지 않는다. 각자 `api/` 폴더에 `.env`를 만들고 아래 이름으로 넣는다.

```
LINER_API_KEY=
VAPI_API_KEY=
STIBEE_API_KEY=
ARTICUL8_API_KEY=
```

```bash
node api/check.mjs
```

점수 스크립트(`scoring/score.mjs`)는 두 단계 위 폴더의 `.env`를 읽게 되어 있다. 저장소에서 돌릴 때는 파일 첫머리의 경로를 `../api/.env`로 바꾼다.
